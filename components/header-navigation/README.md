# Header and Navigation Component

The complete header/navigation markup and behavior are shared across the site:

- Header structure: each page's existing `.site-header` block
- Navigation behavior: `js/navigation.js`
- Header/navigation styles: `css/style.css` and `css/responsive.css`
- Brand assets: `assets/logo/`

Keep logo, navigation labels, dropdown links, and mobile behavior consistent across every HTML page.
